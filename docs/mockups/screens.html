② 버튼을 눌렀을 때
☀🌙
누른 모드로 바로 바뀌고, 그 선택이 이 브라우저에 저장되어 다음 방문에도 유지됩니다.
동작 규칙
· 선택하기 전에는 시스템 설정을 따르고, 컴퓨터의 모드가 바뀌면 같이 바뀝니다
· 컴퓨터와 다른 모드를 고르면 그 선택이 우선입니다(고정)
· 선택은 이 브라우저에만 저장(서버·계정 없음). 저장이 막혀도 화면은 정상, 선택만 유지 안 됨
· 눌린 버튼은 색뿐 아니라 눌림 상태(aria-pressed)로도 알리고, 마우스를 올리면 "라이트 모드"/"다크 모드" 안내가 뜹니다
· 키보드(Tab → Space/Enter)로 조작 가능
시스템 설정으로 되돌리기
새 버튼 없이, 직접 고른 상태에서 지금 컴퓨터와 같은 모드의 버튼을 누르면 저장이 지워지고 다시 컴퓨터 설정을 따릅니다. 그 버튼에 마우스를 올리면 "(누르면 컴퓨터 설정을 따라감)" 안내가 뜹니다.

화면에 영향 없는 곳: 예제 실행 창(격리된 iframe), 보안 설정, 색 팔레트.

설계 의도: 첫 방문은 시스템 설정 그대로, 바꾸고 싶을 때만 아이콘 2개 중 하나를 누른다. 단계가 둘뿐이라 설명 없이 쓸 수 있다.

8. 헷갈리는 짝 · 상태와 규칙
① 검색 결과 없음
“xyz” 와 맞는 비교가 없습니다. 비교는 아직 10개뿐이라 문법 사전에서 찾아 보세요(문법 사전 칩 안내).
② 자료 불러오기 실패
기존과 같게 “항목 없음이 아니라 조회 실패입니다” 경고를 보여 줍니다.
③ 모바일(좁은 화면)
목록 → 비교 순서로 한 화면씩, 상단 “← 목록” 버튼(기존 방식). 표는 가로 스크롤 없이 칸 안에서 줄바꿈.
규칙
· 비교는 항목 모두 일반 개념만(개인 실수담·수업 서버 정보 없음)
· 짝마다 문법 항목 2개 이상과 연결, 연결 id 는 점검 스크립트가 존재 여부 확인
· 주소에 비교 id 를 넣어 공유·새로고침 가능, 옛 주소는 그대로 동작
· 서버·DB·새 라이브러리 없음, 데이터는 data/abap/compare.json 한 파일

설계 의도: 기존 두 사전과 같은 틀(경고 문구·불러오기 실패·좁은 화면)을 그대로 재사용해 새로 배울 것이 없게 한다.
