5. 테마 선택 (새 기능) · 낮/밤 아이콘 버튼 + "시스템 설정 따르기" 체크박스
ERP LensUI5ABAP☀
① 체크함 (기본값)
🌙
컴퓨터가 다크면 다크, 라이트면 라이트로 보입니다. 아이콘은 지금 보이는 모드를 알려 주기만 하고 흐리게 표시되며 눌러도 바뀌지 않습니다.
② 체크 해제 + 라이트
☀
항상 밝게 보입니다. 아이콘(해)을 누르면 ③으로 바뀝니다.
③ 체크 해제 + 다크
🌙
항상 어둡게 보입니다. 아이콘(달)을 누르면 ②로 바뀝니다.
동작 규칙
· 체크를 해제하면 지금 보이는 모드 그대로 시작하고, 이후 아이콘으로 라이트↔다크를 바꿉니다
· 다시 체크하면 시스템 설정을 따릅니다
· 선택은 이 브라우저에만 저장(서버·계정 없음). 저장이 막혀도 화면은 정상
· 아이콘만 있으면 뜻이 안 보이므로 마우스를 올리면 "라이트로 전환"/"다크로 전환" 안내, 화면 낭독기용 이름도 같은 글자
· 키보드(Tab → Space/Enter)로 둘 다 조작 가능
화면에 영향 없는 곳
예제 실행 창(격리된 iframe)과 보안 설정은 그대로입니다. 색 팔레트도 지금 다크 색을 그대로 씁니다.

설계 의도: 한눈에 뜻이 통하는 아이콘 하나로 직접 고르고, "시스템 설정 따르기"는 체크박스로 분리해 기본 동작(시스템을 따름)을 잃지 않게 한다.
